SideBy para Wasmer

1. Reemplaza TU_USUARIO_WASMER en app.yaml y wasmer.toml por tu usuario real de Wasmer.
2. Sube LOS ARCHIVOS Y CARPETAS de esta carpeta a la raiz del repositorio GitHub (no la carpeta contenedora).
3. Conecta ese repositorio en Wasmer Edge y despliega.
4. Si Wasmer muestra errores de manifiesto o build, comparte el error: la configuracion puede variar segun la modalidad de despliegue.

El formulario de SideBy copia el mensaje y abre Instagram; no almacena reservas.
